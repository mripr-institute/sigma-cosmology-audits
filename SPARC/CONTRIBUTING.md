# Contributions and corrections

This repository is a fixed institutional audit record. Contributions should identify a concrete reproducibility or custody issue: identity arithmetic, catalogue provenance, catalogue fields, row selection, coordinate construction, implementation, numerical tolerance, output hash or stated closure predicate.

Do not submit modified scientific data. Provide the exact command, environment, source digest, manifest path, observed output and minimal reproducer. Proposed code changes must preserve the original record and write a new output directory.

Send private or embargo-sensitive reports to `contact@mripr.org`.
